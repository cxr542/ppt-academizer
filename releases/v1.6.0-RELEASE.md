# v1.6.0 — PPTX 입력 전용

## 요약

ppt-academizer는 **PowerPoint(.pptx) → OKESTRO 아카데미 강의안** 변환기입니다. v1.5의 Markdown·텍스트·붙여넣기 입력은 제거했습니다.

## 변경

| 영역 | 내용 |
|------|------|
| API | `/wizard/preview`, `/analyze`, `/academize` — **file(.pptx) 필수** |
| UI | 드롭존 `.pptx` only, 붙여넣기 탭 제거 |
| 코드 | `core/ingest/`, `academize_document` 제거 |

## 사용

```bash
./scripts/run_server.sh
```

`GET /health` → `supported_upload: [".pptx"]`
