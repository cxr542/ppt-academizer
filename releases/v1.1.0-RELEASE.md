# Release 1.1.0 — migrate 품질 (deck_kind · 1:1 · 표 · 차트)

**날짜:** 2026-05-19  
**서비스:** `1.1.0` · **엔진:** `1.1.0`

---

## Summary

`migrate_cmp` 경로를 **CMP 전용 하드코딩**에서 **`deck_kind` 공통 설정**으로 분리했습니다. CONTRABASS·PaaS·generic 파트너 덱에 동일 엔진이 적용됩니다.

---

## Included

| 영역 | 변경 |
|------|------|
| **deck_kind** | `deck_migrate_config.py` — `cmp` \| `contrabass` \| `paas` \| `generic_partner` |
| **슬라이드 1:1** | `classify_slide` → `empty`도 plan에 포함 → 빈 `내지_거버닝 O` |
| **목차** | `add_toc_after_cover` — **cmp만** 자동 목차 |
| **표지** | CMP 부제 하드코딩 제거 — `contrabass`/`paas`는 원본만 |
| **한글 제목** | `extract_header` 스코어링 · `한글: English` 단일 run 보존 |
| **표** | `apply_academy_table_style` + `academy-design.md` §6.5 |
| **차트** | `CHART` / `graphicFrame` → XML clone + `CHART_NOT_COPIED` 경고 |
| **검증** | `SLIDE_COUNT_MISMATCH` · 저장 후 `validate_pptx.py` (실패 시 경고) |
| **fixtures** | `tests/fixtures/manifest.json` + `restore_fixtures.py` |
| **감사** | `audit_slide_mapping.py` — 원본/출력 CSV |

---

## Breaking / behavior change

- CONTRABASS 등: **자동 CMP 목차 슬라이드 없음** → 출력 페이지 수·구조가 v1.0과 다를 수 있음.
- CMP: 기존과 동일하게 목차·`SKIP_SRC_INDICES={8}` 유지.
