# Release 1.0.0 — ppt-academizer + migrate engine

**날짜:** 2026-05-19  
**서비스 버전:** `1.0.0` (`apps/ppt-academizer/core/version.py`)  
**엔진 버전:** `1.0.0` (`cursorstudy/experiments/ppt-test/scripts/migrate_version.py`)

---

## Summary

아카데미 2026 템플릿으로 파트너/CMP형 `.pptx`를 변환하는 **첫 공식 기준선**입니다.

- **웹:** `ppt-academizer` — 드래그앤드롭, `POST /academize`, `POST /analyze`
- **엔진:** `migrate_cmp_deck` (§7 도형 이식) + `spec` 경로 (§5 JSON / Google 이미지 배경)
- **엔진 경로:** `cursorstudy/experiments/ppt-test/` (구 `apps/ppt-test`)

---

## Included

### 웹 서비스 (`apps/ppt-academizer`)

| 기능 | 설명 |
|------|------|
| `/` | 최소 UI — 업로드·프로필(`auto`/`spec`/`migrate_cmp`)·다운로드 |
| `/health` | 템플릿 설정 여부 + **버전 정보** |
| `/academize` | 변환; 헤더 `X-Academize-Warnings`, `X-Academize-Profile`, `X-Academize-Pipeline` |
| `/analyze` | 슬라이드별 layout·texts 미리보기 |

### 변환 파이프라인 (`profile=auto`)

| 경로 | 조건 | 동작 |
|------|------|------|
| **migrate_cmp** | CMP 파일명·파트너형(도형 많음) | `build_cmp_academy.migrate_cmp_deck` |
| **spec** | 그 외 대부분 | `convert_legacy` → JSON → `build_from_json_specs` |
| **google_image** | 이미지-only 슬라이드 비율 높음 | spec + `background_image` |

### migrate 엔진 (§7) — v1.0 동작

- 시드 슬라이드 복제 (`duplicate_slide_from_seed`)
- 본문 도형 이식 (`shape_migrate_lib.copy_shape_hybrid`)
- 표지/간지/본문 레이아웃: `2_표지`, `목차`, `간지`, `내지_거버닝 O`
- **방사형 허브 슬라이드** (CMP 6대 기술): `is_radial_diagram_slide` — 2단 relayout·커넥터 복사 생략
- 저장: `save_academy_deck` + `finalize_academy_package` (폰트/authors 정리, OOXML sanitize)
- CMP 전용: 표지 부제 `클라우드 구현기술 (CMP)`, 슬라이드 2–7 제목으로 **자동 목차** 삽입, `SKIP_SRC_INDICES={8}`

### 기타

- 표지/목차: 원본 1–2장에서 추출 (`front_matter`, PaaS Docker/K8s 하드코딩 목차 **없음**)
- 스모크: `scripts/run_smoke_tests.py` (9항목 통과 기준)
- 스펙 정본: [`academy-design.md`](../../../academy-design.md)

## Known limitations (→ 1.1.0 계획)

다음은 **의도된 1.0 한계**이며 [v1.1.0-PLAN.md](v1.1.0-PLAN.md)에서 다룹니다.

| 영역 | 증상 |
|------|------|
| **덱 종류** | `migrate_cmp` 로직이 **CMP 파일럿** 기준 — CONTRABASS/PaaS도 동일 분기 |
| **슬라이드 누락** | `classify_slide` → `empty` 이면 plan에서 **제외** (예: CONTRABASS 7·8페이지) |
| **허수 페이지** | CMP형 **자동 목차** 삽입으로 원본과 페이지 매핑 불일치 |
| **제목/언어** | 헤더 추출 휴리스틱 오류 시 **영문만** ph10에 들어갈 수 있음; CMP 표지 부제 하드코딩 |
| **표** | `clone_shape_xml`만 사용 — **아카데미 폰트/색 미적용**, 테마 scheme 깨짐 시 가독성 저하 |
| **차트** | CHART/graphicFrame **전용 이식 없음** — 조용히 누락 가능 |
| **허브 연결선** | radial 슬라이드에서 커넥터 생략 → **선 없는 다이어그램** |
| **PowerPoint** | 일부 파일에서 **복구** 팝업 가능 (sanitize로 완화, 100% 아님) |
