# Release 1.4.0 — 품질 모드·독립 엔진 번들

**날짜:** 2026-05-20  
**서비스:** `1.4.0` · **번들 엔진:** `engine/` (ppt-test `1.2.9` 동기화)

---

## Summary

표준/대용량 품질 모드(1.4.0)와 함께, **monorepo `ppt-test` 경로 없이** `apps/ppt-academizer`만으로 서버·스모크·테스트를 돌릴 수 있도록 **번들 엔진**(`engine/`)을 도입했습니다.

---

## Included

| 영역 | 내용 |
|------|------|
| **독립 실행** | `engine/scripts/*` — `resolve_ppt_test_root()`가 `engine/` 우선 |
| **동기화** | `scripts/sync_engine_from_ppt_test.py` |
| **pytest** | `tests/conftest.py` — PYTHONPATH 자동 |
| **스모크** | `cmp-like-partner` fixture 8장+ — `migrate_cmp` 라우팅 회귀 |
| **문서** | README·PLAN 상태, `docs/standalone.md` |

---

## Verify

```bash
cd apps/ppt-academizer
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest tests/ -q
.venv/bin/python scripts/run_smoke_tests.py
./scripts/run_server.sh
```

`GET /health` → `engine_root`가 `…/apps/ppt-academizer/engine` 인지 확인.

엔진 갱신(ppt-test 수정 후):

```bash
python scripts/sync_engine_from_ppt_test.py
```
