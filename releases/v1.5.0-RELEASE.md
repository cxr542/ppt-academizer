# Release 1.5.0 — Markdown·텍스트 입력 (Phase 1)

**날짜:** 2026-05-20  
**서비스:** `1.5.0`

---

## Summary

`.md` / `.txt` 파일 업로드와 **글 붙여넣기**로 아카데미 `.pptx`를 생성합니다. 변환은 **spec(§5)** 파이프라인만 사용합니다.

---

## Included

| 영역 | 내용 |
|------|------|
| **ingest** | `core/ingest/` — md/txt → `NormalizedDeck` |
| **spec** | `core/spec_from_normalized.py` |
| **API** | `/wizard/preview`, `/analyze`, `/academize` — file 또는 `paste_text` |
| **UI** | 파일 / 붙여넣기 탭, `.pptx·.md·.txt` accept |
| **PDF** | 400 + 안내 (Phase 2) |
| **문서** | [docs/md-authoring.md](../docs/md-authoring.md) |
